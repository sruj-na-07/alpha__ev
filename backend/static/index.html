🔌 API Endpoints Summary (/api/v1)

  • POST /api/v1/upload — Upload dataset file (CSV/XLSX)
  • GET /api/v1/datasets — List uploaded datasets
  • POST /api/v1/datasets/{id}/clean — Run data cleaning & duplicate detection
  • POST /api/v1/datasets/{id}/classify — Run 22-label aspect classification
  • POST /api/v1/datasets/{id}/analyze-sentiment — Run sentiment & emotion analysis
  • GET /api/v1/reviews/{id}/explain — Generate SHAP feature attribution
  • GET /api/v1/datasets/{id}/dashboard — Get dashboard intelligence stats
  • GET /api/v1/datasets/{id}/export?format=csv — Export processed reviews
  • POST /api/v1/datasets/{id}/chat — SQL-grounded chatbot query
  • PUT /api/v1/predictions/{id} — Human correction of aspect predictions
